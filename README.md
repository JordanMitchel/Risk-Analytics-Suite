# Fixed-Income-Risk-Dashboard
A full-stack risk management dashboard for fixed income portfolios, built with Python + QuantLib + React.

##🚀 Project Overview

This project demonstrates how to integrate quantitative finance analytics with a modern web dashboard.

###Backend (Python + C++ QuantLib)

FastAPI service exposing risk APIs

QuantLib-based calculations (DV01, duration, convexity, exposures)

Yield curve bootstrapping from market instruments

###Frontend (React + TypeScript + Recharts/Plotly)

Interactive dashboard

Yield curve charts, DV01 tables, exposure bar charts

Portfolio-level risk aggregation

###Infrastructure

Dockerized backend & frontend

Shared JSON schemas for API contracts

CI/CD ready (GitHub Actions / GitLab CI)
